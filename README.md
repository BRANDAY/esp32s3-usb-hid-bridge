# USBHelper — учусь программировать ESP32 mini

Учебный проект: прошивки для микроконтроллера ESP32 mini и общение с ним
с компьютера.

**Новичок? Начни с [docs/esp32-guide.md](docs/esp32-guide.md) — там всё
объяснено с нуля: что такое ESP32, что он умеет и как с ним разговаривать.**

## Структура

| Путь | Что это |
|---|---|
| `src/main.cpp` | текущая прошивка: мигалка + команды по Serial |
| `scripts/serial_chat.py` | чат с платой с компьютера (Python + pyserial) |
| `docs/esp32-guide.md` | гайд для старта |
| `platformio.ini` | конфигурация сборки (PlatformIO), 3 варианта mini-плат |

## Быстрый старт

1. Подключи плату ESP32 mini к USB (кабель с данными, не «только зарядка»)
2. Прошей: `python -m platformio run -t upload`
3. Общайся: `python scripts/serial_chat.py` → набери `help`

Или просто открой Claude Code в этой папке и скажи: «прошей плату».

## Как это работает

PlatformIO при первой сборке скачивает компилятор → C++ превращается в
`firmware.bin` → esptool записывает его во flash платы через USB → плата
перезагружается и выполняет твой код. USB-порт при этом остаётся каналом
связи ПК ↔ плата (115200 бод).
