# USBHelper — учусь программировать ESP32-S3 mini

Учебный проект: прошивки для микроконтроллера ESP32-S3 mini и общение с ним
с компьютера.

**Новичок? Начни с [docs/esp32-guide.md](docs/esp32-guide.md) — там всё
объяснено с нуля: что такое ESP32, что он умеет и как с ним разговаривать.**

## Структура

| Путь | Что это |
|---|---|
| `src/main.cpp` | учебная прошивка №1: мигалка + чат по serial (окружение `s3mini`) |
| `src/hid_composite.cpp` | прошивка №2: USB-клавиатура + мышь + COM-порт (окружение `s3hid`) |
| `scripts/serial_chat.py` | консоль для команд плате (Python + pyserial) |
| `docs/esp32-guide.md` | гайд для старта |
| `platformio.ini` | конфигурация сборки: два скетча через `build_src_filter` |

## Две прошивки

Проект собирает разные прошивки под разные окружения (`-e <env>`):

- **`s3hid`** (по умолчанию) — плата притворяется USB-клавиатурой и мышью,
  плюс отдаёт виртуальный COM-порт для текстовых команд.
- **`s3mini`** — первая учебная: мигает светодиодом и отвечает по serial.

## HID: клавиатура + мышь + COM-порт

Плата — составное USB-устройство: одним кабелем компьютер видит **клавиатуру**,
**мышь** и **COM-порт** одновременно. Ты шлёшь в порт текстовые команды — плата
исполняет их как реальный ввод.

```
python -m platformio run -e s3hid -t upload   # прошить
python scripts/serial_chat.py                 # открыть консоль команд
```

Команды (строка + Enter): `type <текст>`, `key enter|esc|f5|...`,
`combo ctrl+c`, `move <dx> <dy>`, `click`, `scroll <n>`, `help`, `info`.
Полный список — командой `help` или в [src/hid_composite.cpp](src/hid_composite.cpp).

Предохранитель: `disarm` блокирует ввод, `arm` — снова разрешает.

### ⚠️ Важно про прошивку HID-версии

Когда плата работает как клавиатура (режим USB-OTG), временный порт для
прошивки исчезает, и автосброс esptool не срабатывает. Поэтому:

1. Перед заливкой переведи плату в **режим загрузки**: выдерни из USB,
   зажми **BOOT**, воткни обратно, отпусти BOOT.
2. Прошей: `python -m platformio run -e s3hid -t upload`.
3. **Выдерни и воткни плату заново** (или нажми RST) — чтобы она стартовала
   в рабочую прошивку. Программный сброс на «родном» USB не всегда срабатывает.

## Как это работает

PlatformIO при первой сборке скачивает компилятор → C++ превращается в
`firmware.bin` → esptool записывает его во flash платы через USB → плата
перезагружается и выполняет твой код. USB-порт при этом остаётся каналом
связи ПК ↔ плата (115200 бод).
